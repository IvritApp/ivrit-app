# Hirbis — приложение для изучения иврита (для русскоязычных)

Этот файл Claude Code читает сам при запуске в этой папке. Полная память проекта лежит в `claude-docs/`.
Эта папка не уходит на GitHub (см. `.gitignore`), потому что репозиторий публичный.

Остальные документы читай по необходимости:

- `claude-docs/prompt-alfavit.md`: промпты для картинок алфавита.
- `claude-docs/kino-prilet.md`: сценка «прилёт».
- `claude-docs/shablon.md`: шаблон урока.

## Кто я и как со мной работать
- Делаю приложение один. Программирую на базовом уровне, поэтому объясняй по-русски, просто и по шагам. Кратко.
- Около 1 часа в день. Цель — рабочая бета (Telegram Mini App) к Новому году, затем iOS и Android.
- Есть два знатока иврита, они проверяют уроки. Знаток 2 отвечает за правила орфографии (см. osnova.md).

## Как устроено
- Чистый HTML/CSS/JS без сборки. Хостинг — GitHub Pages: ivritapp.github.io/ivrit-app. Публикую через GitHub Desktop: Commit → Push.
- После правки JS/CSS обязательно поднимай `?v=` у всех подключений в `index.html` (сейчас v=20261123b).
- В конце работы ВСЕГДА давай готовое название коммита (Summary) отдельным блоком кода.
- Сервер (VPS) я обслуживаю сам. Команды для сервера давай одной строкой в блоке `bash` — я запускаю их в PowerShell (префикс `!` в приложении Claude не срабатывает). Только читать (логи, `py_compile`, тест в `/tmp`) Claude может сам; менять сервер (restart, systemctl) — только я.
- Вызовы анимаций оборачивай в `if (window.HAnim)`.
- На компьютере НЕТ Python и Node. Локальная проверка: превью «hirbis» из `.claude/launch.json` (PowerShell-сервер `claude-docs/tools/serve.ps1`, порт 8765) во встроенном браузере. Проверка сервера — копия в `/tmp` на VPS: `python3 -m py_compile`, тест `claude-docs/tools/chat_test.py` (временная база, порт 8099). Картинки из SVG — headless Edge (`--screenshot`).
- Мои файлы вне репозитория: `C:\Users\user\Desktop\Клод\Project\ivrit-app` (аватарки бота, видео Duolingo, промпты), журнал — `C:\Users\user\Desktop\Клод\hirbis-zhurnal.html`.

## Безопасность (строго)
- Никогда не проси и не принимай в чат ключ бота, пароль админа или ключ страницы знатока.
- Не клади секреты и внутренние процедуры админа в файлы вне `claude-docs/`, потому что репозиторий публичный.
